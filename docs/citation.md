# Citing KBank

If you use **KBank** in your research, glycan curation, or publications, please cite the software using the metadata below.

=== "BibTeX"

    ```bibtex
    @software{Stanton_KBank,
      author       = {Stanton, Thomas David},
      title        = {{KBank: Geno-glycomic database for bacterial glycans}},
      url          = {https://seroverse.github.io/KBank/},
      repository   = {https://github.com/SeroVerse/KBank},
      license      = {GPL-3.0-only}
    }
    ```

=== "APA"

    ```text
    Stanton, T. D. KBank: Geno-glycomic database for bacterial glycans [Computer software]. https://github.com/SeroVerse/KBank
    ```
